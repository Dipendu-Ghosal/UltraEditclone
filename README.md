# UltraEdit Clone

A static, responsive front-end clone of the [UltraEdit](https://www.ultraedit.com/) text editor download page. 

## 📝 Overview

This project is a simple web development practice project aimed at recreating the layout and styling of the UltraEdit Windows download page. It uses pure HTML and CSS to create a clean, responsive user interface.

## 🚀 Features

- **Responsive Design**: The layout adapts to different screen sizes, converting the multi-column download grid into a single column on mobile devices (screens smaller than 900px).
- **Modern UI Elements**: Includes navigation menus with SVG icons, styled buttons, and a clean typography hierarchy.
- **CSS Grid & Flexbox**: Utilizes modern CSS layout modules for structuring the header, main content area, and the download grid.

## 🛠️ Technologies Used

- HTML5
- CSS3 (Vanilla CSS)

## 📁 Project Structure

- `index.html`: The main HTML document containing the structure of the webpage.
- `style.css`: The stylesheet containing all the styling and media queries for responsiveness.

## 🏃‍♂️ How to Run

Since this is a static website, you don't need any special server to run it.

1. Clone or download this repository to your local machine.
2. Navigate to the project directory.
3. Simply open `index.html` in any modern web browser (e.g., Chrome, Firefox, Edge, Safari).
